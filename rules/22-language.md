# Language

Every file is written in English. No exceptions.
Code, comments, docstrings, commit messages, PR text, `context/`, `rules/`, `memory/`, `CLAUDE.md`, configs, plan files — all English.

Korean is for live conversation with the user only. Nothing that gets written to disk is in Korean.

Why: one language across the codebase keeps it searchable, tool-friendly, and contributor-ready, and avoids mixed-script drift accumulating over sessions.

When editing an existing file that is still in Korean (legacy), write the new/changed content in English; migrate the rest opportunistically.
